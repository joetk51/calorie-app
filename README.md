# カロリー記録アプリ

写真を撮るとAI（Gemini）が食事内容を解析し、カロリーとPFC（たんぱく質・脂質・炭水化物）を自動計算してくれる、完全無料の個人用Webアプリです。

- サーバー不要（静的ファイルのみ）
- データはブラウザ内（localStorage）に保存され、外部には送信されません（Gemini APIへの画像送信を除く）
- ホスティングはGitHub Pagesなどの無料枠を想定

## 1. 無料のGemini APIキーを取得する

1. https://aistudio.google.com/apikey にアクセスし、Googleアカウントでログイン
2. 「Create API key」でキーを発行（無料）
3. 発行されたキー（`AIzaSy...`）をコピー

無料枠には1分あたり・1日あたりのリクエスト数制限がありますが、個人の食事記録用途であれば十分です。

## 2. ローカルで試す

`index.html` をブラウザで直接開くだけで動作します。インストール不要です。

## 3. 無料で公開する（GitHub Pages）

1. GitHubで新しいリポジトリを作成（Public）
2. このフォルダの中身（index.html, style.css, app.js）をpush
3. リポジトリの Settings → Pages → Branch を `main` / `root` に設定
4. 発行されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）にスマホ・PCからアクセス

## 4. 使い方

1. 初回は「設定」タブでAPIキーを入力・保存
2. 「記録」タブで写真を選択・撮影 →「AIで解析する」
3. 解析結果（料理名・カロリー・PFC）を確認し、必要なら修正して保存
   - 「量の倍率」で全体量を一括調整可能（例: 半分食べた場合は0.5）
4. 「今日」タブで当日の合計・目標に対する進捗を確認
5. 「履歴」タブで過去の記録・週間グラフを確認
6. 「設定」タブでデータのエクスポート（バックアップ）・インポートが可能

## 注意事項

- データはブラウザ単位で保存されるため、機種変更やブラウザ変更の前に必ず「エクスポート」でJSONバックアップを取ってください。
- AIによる推定値なので、目安として利用してください。誤差が大きい場合はフォームで手動修正してください。
- APIキーはこの端末のブラウザ内にのみ保存されます（Google以外の第三者には送信されません）。共有PCでは利用後に設定タブでキーを削除することを推奨します。
